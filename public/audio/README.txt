# 🎵 CreamSkin Custom Music

Place your custom MP3 background music file here with the name:

`music.mp3`

Path: `public/audio/music.mp3`

CreamSkin Radio will automatically detect and play this audio file whenever the user presses play (🎵) in the top navbar!
If no file is present, it will automatically fall back to the built-in procedural ambient synth.
